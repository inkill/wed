# Свадебное приглашение — Илья & Екатерина

Одностраничный сайт-приглашение на свадьбу **27 февраля 2027 года** со отдельной страницей шафера.

- `index.html` — главная страница приглашения
- `shafer.html` — личная страница шафера жениха (чек-лист и план дня)

Сайт полностью статический: работает на GitHub Pages без сборки и настройки.

---

## Как опубликовать на GitHub Pages

1. Создайте новый репозиторий на GitHub (например, `wedding`).
2. Загрузите в репозиторий **все файлы из этой папки** — так, чтобы `index.html` лежал в корне репозитория:
   - через веб-интерфейс: «Add file → Upload files», перетащите содержимое папки и нажмите «Commit changes»;
   - или через git:
     ```bash
     git init
     git add .
     git commit -m "Свадебное приглашение"
     git branch -M main
     git remote add origin https://github.com/ВАШ_ЛОГИН/wedding.git
     git push -u origin main
     ```
3. Откройте в репозитории **Settings → Pages**.
4. В разделе «Build and deployment» выберите **Source: Deploy from a branch**, ветка **main**, папка **/(root)** и нажмите «Save».
5. Через 1–2 минуты сайт будет доступен по адресу:
   `https://ВАШ_ЛОГИН.github.io/wedding/`

Ссылку можно отправлять гостям — при пересылке в WhatsApp или Telegram к ней автоматически подтянется красивый превью-заголовок.

## Что заменить на реальные данные

В коде места с заглушками помечены комментарием `<!-- ЗАМЕНИТЕ: ... -->`:

| Что | Где |
| --- | --- |
| Название площадки и адрес | `index.html` — карточка «Место» |
| Время сбора и церемонии | `index.html` — карточка «Тайминг» |
| Пункты и время программы дня | `index.html` — блок «Программа дня» |
| Время плана дня шафера | `shafer.html` — блок «План дня шафера» |

Откройте файл любым текстовым редактором, найдите текст заглушки и впишите свои данные, затем закоммитьте изменения — сайт обновится сам.

## Структура проекта

```
├── index.html          # Главная страница-приглашение
├── shafer.html         # Страница шафера (чек-лист + план дня)
├── favicon.svg         # Иконка сайта
├── css/
│   ├── fonts.css       # Подключение локальных шрифтов
│   └── style.css       # Все стили сайта
├── js/
│   └── main.js         # Отсчёт времени, анимации, чек-лист
└── assets/
    ├── fonts/          # Шрифты Cormorant Garamond и Montserrat (кириллица)
    └── img/            # Акварельные иллюстрации
```

## Примечания

- Отсчёт идёт до **27 февраля 2027, 15:00** (время церемонии). Если церемония в другое время — поправьте строку `new Date(2027, 1, 27, 15, 0, 0)` в `js/main.js` (месяц `1` — это февраль, отсчёт с нуля).
- Галочки в чек-листе шафера сохраняются в браузере того, кто их ставит.
- Шрифты и картинки лежат внутри проекта — сайт работает даже без интернета.
